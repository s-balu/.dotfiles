# .dotfiles

Note: do a `ln -s $HOME/.dotfiles/dot_zshrc ~/.zshrc` or your shell will most likely complain!

Over the years I have become used to have a few softwares that makes my life easier on the terminal. In no specific order they are:

* [zsh](https://www.zsh.org) (obviously, because I am not a caveman!)
* [ohmyzsh](https://ohmyz.sh) (for sane zsh defaults)
* [tmux](https://github.com/tmux/tmux/wiki) (so that I can have splits and do matrix-style stuff)
* [ohmytmux](https://github.com/gpakosz/.tmux) (sane defaults for tmux)
* [starship](https://starship.rs) (better terminal prompt)
* [zoxide](https://github.com/ajeetdsouza/zoxide) (better cd)
* [eza](https://eza.rocks) (better ls)
* [neovim](https://neovim.io) (vim: THIS IS THE WAY!; nvim: we are in the 21st century people.)
* [lazyvim](https://www.lazyvim.org) (minimal maintenance)
* [lazygit](https://github.com/jesseduffield/lazygit) (fancy git interface)

Some/most of them need rust to work/install.
